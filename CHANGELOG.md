# Changelog

All notable changes to this project will be documented in this file.

Versioning of this project adheres to the [Semantic Versioning](https://semver.org/spec/v2.0.0.html) spec.

## [0.3.0]

- Added `--user-agent` option to prepend a custom value to the User-Agent header.
  The default value (`overpass-cli/<version>`) is still included at the end, even
  when this option is set, to help Overpass API servers accurately identify requests
  from this client.
- Tweak `--help` text styling generated by Clap, to only use plain text (no bold or
  underline styles, which don't work in all terminals).

## [0.2.1]

- Added `--timeout` argument to set query timeout
- Added `--mem` argument to set query max memory (`maxsize` in Overpass QL)
- Exit with error if query contains settings that conflict with provided CLI args

## [0.2.0]

- Added `--area` argument to geocode a search string with Nominatim and then
  make the result available for use in the query as the default `area` value.
- Add `User-Agent` header to all outgoing HTTP requests.

## [0.1.1]

- Fixed a bug where `--date`, `--diff`, and `--adiff` arguments weren't
  correctly quoted, requiring the user to wrap them in quotes themselves
  to use them.

## [0.1.0]

Initial release.
